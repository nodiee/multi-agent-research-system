# Multi-Agent Research System

AI-powered multi-agent research pipeline using:
- LangChain
- Mistral AI
- Tavily Search
- BeautifulSoup
- Streamlit

## Features
- Search Agent
- Reader Agent
- Writer Chain
- Critic Chain
- Web Scraping
- Research Report Generation

## Tech Stack
- Python
- LangChain
- Streamlit
- Mistral AI
- Tavily API
